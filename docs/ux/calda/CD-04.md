# CD-04: Motion dan QA akhir (18 November 2026)

Tiket terakhir rangkaian Calda/Veyla, disetujui PO bersama merge CD-03.

## Motion

Sebagian besar gerak Calda/Veyla sudah terpasang di tiket sebelumnya (kapsul navigasi bergeser,
tab bar, chip merek, count-up KPI admin, ikon tema berputar, stagger kartu). CD-04 menambah:

| Gerak | Tujuan (antislop R-19) | Berkas |
| --- | --- | --- |
| Kepala seksi naik-pudar saat masuk layar | Judul seksi muncul lebih dulu, isi menyusul lewat stagger-nya sendiri; menandai awal bagian baru saat menggulir | `components/section.tsx` (memakai `Reveal`) |
| Tile pemeriksaan harian menyapu per kolom, sekali | Membaca grid dari tanggal lama ke baru; selesai < 1 s (batas data reveal) | `components/admin/tile-sweep.tsx`, `refresh-heatmap.tsx` |

Sengaja tidak dianimasikan: h1 hero publik. Menyembunyikannya sampai JavaScript jalan akan menunda
LCP (antislop R-40). `Reveal` dan `TileSweep` melewati elemen yang sudah terlihat saat halaman
dibuka dan diam saat reduced motion.

## QA

- Gulir penuh `/`, `/products`, `/how-it-works`, `/admin` dengan dan tanpa reduced motion: 0 elemen
  tertinggal tersembunyi, 0 error konsol.
- Audit anti-slop mode after: `docs/ux/anti-slop/audit-004-2026-11-18.md` (5 temuan bernomor,
  menunggu pilihan PO).
- Lighthouse mobile produksi: aksesibilitas, best practices, SEO 100; CLS 0; performa 76-90 (lihat
  audit 004 no. 2).
