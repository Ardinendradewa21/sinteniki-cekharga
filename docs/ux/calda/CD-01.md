# CD-01: Navigasi gaya Calda (18 November 2026)

Disetujui PO bersama merge CD-00. Mengganti menu ponsel (panel turun dari tombol ☰) dengan
tab bar bawah, dan header desktop dengan kapsul bergaya Calda.

## Perubahan

| Bagian | Isi | Berkas |
| --- | --- | --- |
| Header desktop | Menu dalam satu track, ikon + label; menu aktif kapsul monokrom (`--primary`) yang bergeser lewat `layoutId`; di `md` hanya menu aktif berlabel. Cari dan tema = tombol bulat bertepi; ikon tema berputar saat berganti | `src/components/layout/main-nav.tsx` |
| Ikon | Satu peta ikon dengan alasan per ikon (antislop R-04), tanpa ikon "sparkle" untuk AI | `src/components/layout/nav-icons.ts` |
| Tab bar ponsel | Beranda, Produk, Bandingkan, Tanya AI, Lainnya; tab aktif bergeser; lembar "Lainnya" (Cara Kerja, Cari menurut kebutuhan, Pertanyaan umum, Beriklan, Ketentuan layanan) | `src/components/layout/mobile-tab-bar.tsx`, `MORE_NAV` di `src/lib/navigation.ts` |
| Ruang bawah | `--tabbar-offset` (78px + safe area di ponsel, 0 mulai `md`): padding halaman, compare tray, banner persetujuan, composer Tanya AI | `globals.css`, `compare-tray.tsx`, `consent-banner.tsx`, `assistant/chat.tsx` |

## Temuan saat QA dan perbaikannya

1. Tab bar awalnya dirender di dalam kapsul header: `backdrop-filter` membuat `position: fixed`
   relatif ke kapsul. Dipindah ke layout publik.
2. "Bandingkan" terpotong di 375px: padding tab dirapatkan, teks tetap 12px (TC-A11Y-06).
3. Compare tray menimpa tab bar 2px (garis kaca 1px atas-bawah tidak dihitung): offset kini 78px,
   tinggi tab dikunci `h-14` (TC-NAV-03).
