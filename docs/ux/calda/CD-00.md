# CD-00: Fondasi tema Calda (18 November 2026)

Keputusan PO (18 November 2026): situs publik mengikuti gaya template Calda
(demo.codeandchill.store/calda, dashboard smart-home berbayar), admin mengikuti Veyla (AV-01).
Referensi visual saja; kode, ikon, foto, dan teks template tidak disalin. Tangkapan referensi di
`design/references/calda/` (di-ignore git).

Pilihan PO: abu netral Calda + aksen **biru**, font **Urbanist**, latar **gradasi abu tanpa foto**,
dikerjakan **bertahap per tiket**.

| Aspek | Calda | Di CekHarga |

## Yang dikerjakan di CD-00

- Token Frost/Smoke (`src/app/globals.css`), kontras diukur rumus WCAG lalu dipindai di halaman nyata.
- Urbanist di root layout (`src/lib/fonts/urbanist.ts`); `.tabular`/`tabular-nums` memakai Plus Jakarta Sans.
- Kaca bertepi kilau diagonal, radius baru, bobot heading 700/600, teks biasa 500.
- Tanda logo dan CTA monokrom (hitam di Frost, putih di Smoke); biru untuk status aktif dan tautan.
- Titik status "napas" admin kini dua siklus lalu diam (antislop R-19/R-39).
- Dokumen: PRD §8, DESIGN.md (B12), AGENTS.md, CLAUDE.md, ADS-CONTEXT §12.2, skill `cekharga-antislop`.
