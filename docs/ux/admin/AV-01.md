# AV-01: Admin bertema Veyla (18 November 2026)

Keputusan PO: admin mengambil gaya template Veyla (demo codeandchill.store, berbayar) sebagai
referensi visual saja. Tidak ada kode, ikon, foto, atau teks Veyla yang disalin; tangkapan
referensi di `design/references/veyla/` (di-ignore git).

## Yang diterapkan

| Bagian | Isi | Berkas |
| --- | --- | --- |
| Token | Kanvas `#EDEDEF`, kartu putih radius 22px + cincin tipis + bayangan lembut, tinta `#151112` (CTA, kartu sorotan), mint `#CCE5E2` (permukaan aktif/positif), teal `--brand` untuk teks/grafik. Gelap: kanvas `#111314`, kartu `#1A1D1E`, mint `#7FB0A9`. Hanya di `.admin-theme` | `src/app/globals.css` |
| Font | Urbanist hanya di rute admin (`src/app/admin/layout.tsx`); angka `tabular-nums` tetap Plus Jakarta Sans (Urbanist tanpa `tnum`) | `src/lib/fonts/admin.ts` |
| Shell | Sidebar sewarna kanvas, pencarian produk Ctrl/⌘ K, menu berkelompok (Katalog, Monetisasi) dengan penanda aktif bergeser, kartu tinta "Situs publik", kartu akun + keluar; topbar remah roti + tema + Tambah produk; tab bar bawah di layar kecil | `src/components/admin/admin-shell.tsx` |
| Dasbor | Sapaan WIB + ringkasan satu baris dari data, pil status backend bertitik "napas", KPI mint/putih/tinta/putih+cincin, angka KPI bergulir saat dibuka | `src/app/admin/(workspace)/page.tsx`, `kpi-count.tsx`, `ring-gauge.tsx` |
| Login | Memakai `.admin-theme` | `src/app/admin/login/*` |

## Batasan yang dijaga

- Kontras terukur (skrip kontras): terburuk muted/kanvas 5.87:1 terang, 7.97:1 gelap; garis 3.79:1.
  Mint hanya permukaan; grafik tipis memakai teal.
- Animasi hanya transform/opacity lewat `motion/react` dan preset `src/lib/motion.ts`; reduced
  motion langsung ke nilai akhir. Angka bergulir hanya untuk jumlah di admin, bukan harga.
- Target sentuh 44px, fokus terlihat, tanpa overflow horizontal di 375px.
