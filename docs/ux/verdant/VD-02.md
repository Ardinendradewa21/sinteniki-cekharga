## Bug dan masalah yang diperbaiki

1. **Konten tersembunyi sebelum JavaScript jalan** (antislop R-40, audit 002 no 8). `Reveal`, `StaggerList`, dan `RevealItem` merender `opacity: 0` ke HTML server, termasuk elemen di atas lipatan. Kini HTML server selalu terlihat.
2. **Reduced motion masih memudar.** `reducedMotion="user"` tidak mematikan opacity, jadi entrance tetap berjalan. Kini reveal dan CountUp tanpa animasi saat reduced motion.
3. **Stagger tanpa batas** (80ms × semua item). Kini 50ms dan maksimal 8 item yang dijeda.
4. **Skrip scene membuat gambar tegak** dari foto potret. Kini dipotong 16:10.
5. **Screenshot QA halaman penuh** menampilkan area kosong untuk elemen reveal. Skrip screenshot kini menggulir dulu (catatan di DESIGN.md §8.1).
