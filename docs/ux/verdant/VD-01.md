## Bug dan masalah yang diperbaiki

1. `text-brand` dan tombol `link` turun ke 4.21:1 di canvas Verdant Day. Sekarang memakai `--brand-text`.
2. `--brand-text` DESIGN.md (`#0f6c46`) hanya 4.38:1 di chip `--brand-muted` di atas canvas. Diganti `#0d6340` (4.96:1).
3. CSS mati `.draw-outline` dan `@keyframes ch-draw-outline` (komponen `hero-device.tsx` sudah dihapus) dihapus.
4. Gradien terracotta dan `backdrop-blur` di modul iklan (lihat tabel).
5. Warna Tailwind mentah di komponen publik (lihat tabel). Hex warna merek marketplace di `marketplace-logo.tsx` sengaja dipertahankan: identitas pihak ketiga, bukan warna UI.
6. Tes e2e TC-IMP-01 usang sejak Sprint 14 (`bfff474`) karena tab diganti nama; gagal di setiap run smoke.
7. `/style-guide` memuat daftar hex tulis tangan yang bisa berbeda dari CSS dan swatch terracotta.
